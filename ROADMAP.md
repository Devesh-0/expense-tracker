# Roadmap

## Completed (v1.0)

- `Expense` model with encapsulated fields
- Console menu to add, view and delete expenses
- Category-wise summary with total spending (`HashMap`)
- Daily and monthly spending summaries (`TreeMap`)
- CSV storage: data is saved after every change and loaded on startup
- Input validation for amounts, dates and menu choices

## Planned

- Edit an existing expense
- Monthly budget limit with warnings
- Export a formatted `.xlsx` report using Apache POI
- Store data in MySQL using JDBC
- Unit tests with JUnit
- Desktop GUI with JavaFX
